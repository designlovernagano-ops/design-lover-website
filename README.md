# Design Lover — 公式ホームページ

> 思いを、カタチに。

長野県宮田村を拠点とする「機械設計者 × AIコンサルタント」のウェブサイトです。既存のHTML/CSS構成と写真素材を生かして、2026年9月に内容を更新しました。

## 掲載内容

- 治具・装置設計、3Dモデル・図面作成、3Dプリント・試作
- AI導入支援、AIを活用したWeb制作、GAS自動化（準備中）
- プロフィール、仕事で大切にすること、ご依頼の流れ
- 個別見積もりの案内、ココナラ・メールへの問い合わせリンク

## ファイル

- `index.html`: ページ本文・ナビゲーション・問い合わせ先
- `styles.css`: 配色、文字、スマートフォン向けの表示
- `site.js`: スマートフォン用メニューの開閉、キーボード操作

外部ライブラリやインストール作業は不要です。JavaScriptが無効でも、本文と問い合わせリンクを利用できます。フォントはGoogle Fontsを使用し、読み込めない場合は端末のフォントで表示します。

## 手元で確認する

PowerShellで次の順に実行してください。

```powershell
Set-Location 'C:\Users\desig\design-lover-website'
python -m http.server 8080 --bind 127.0.0.1
```

ブラウザーで [ローカルプレビュー](http://127.0.0.1:8080/) を開きます。終了するときは、起動した画面で Ctrl+C を押します。
